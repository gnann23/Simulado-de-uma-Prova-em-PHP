Simulado da Prova 
Nesta atividade, vocês irão desenvolver mini-sistemas em PHP, todos executados pelo terminal.
O objetivo é revisar de forma integrada os conteúdos estudados no 1º bimestre e se preparar para o formato da prova.
Os sistemas foram pensados para exigir interpretação, organização da lógica, validação de dados, uso de estruturas de repetição, arrays, funções e geração de relatórios.
